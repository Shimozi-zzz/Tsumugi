# 0036 · 声优图谱改为搜索驱动的"以人为中心"邻域视图（ego network）

日期：2026-08-08
状态：已接受

## 一、为什么从"全局图"转向"邻域视图"

用户最新反馈确认：上一轮（ADR 0035）解决的是**标签重叠**，但问题的根本不是标签，
是**全局图本身的边密度**——357 声优 / 2324 边同时渲染时连接线交织成不可读的
"毛线球"，这在任何图密度这么高的场景下都无解，不是继续调布局参数能解决的。

因此把渲染对象从"整张全局关系图"改为**"以搜索选中的单个声优为中心的邻域视图"
（ego network）**：无论库里有 1020 位声优，用户任意时刻看到的都只是"一个人的配音
关系网络"——规模天然小（一位声优通常几部到十几部作品），小到不需要复杂布局算法，
放射状排布即可清晰可读。

## 二、方案

### 1. 搜索优先入口（默认态）
- 页面顶部搜索框：复用命令面板的 `matchCommand` 模糊匹配（子串 + 去空格小写）；
- 默认（未选中）**不渲染全局大图**：展示引导文案"搜索一个声优开始探索" +
  "配音作品最多的声优"快捷入口（按 work_count 取前 8 位，如 坂本真綾/子安武人/
  花泽香菜/能登麻美子…），不强制列全部。

### 2. 单声优邻域视图（核心，`buildEgo` + `layoutEgoGraph`）
- 中心：选中声优（accent 大圆）；
- 内环（R=150）：TA 配音过的**全部作品**；角色小圆点置于 声优→作品 线段中点偏移；
- **外环（R=270）共同出演声优**：与 TA 配过同一部作品的其它声优，只表达"共同出演
  过"这层关系（连到共享作品），**不展开这些声优各自的其他作品**，避免滚雪球又变
  大图；按共享作品数排序、截断到 cap=40；
- 标签：中心声优强制显示；作品与共同出演声优按连接数优先级 + 碰撞避让（复用
  ADR 0035 的 `pickLabels`）——实测 0 重叠。

### 3. 全局概览降级为可选模式
- 旧全局图不丢弃，保留为"查看全部声优网络"入口（**非默认**）；
- 进入时明确提示：`全局概览：同时渲染 N 位声优 / M 部作品，数据量大、边密集，
  可能难以阅读——建议用顶部搜索聚焦单个声优`；保留阈值 2/3/5/8 调节。

### 4. 入口联动
- 角色墙点角色声优名 → `setVoiceFocus(声优名)` → 图谱**直接进入该声优邻域视图**
  （不是全局图再手动找）；
- 命令面板"打开声优图谱" → `setVoiceFocus(null)` + 进入声优图谱 → **搜索入口页**；
- DesktopView：离开 voice 区时清空 voiceFocus，避免再次进入时重新聚焦旧声优。

## 三、明确保留/不做
- 交互不变：点作品/角色 → 复用主从视图跳详情；点共同出演声优 → 切换到该声优的
  邻域；
- 视觉走 token；仍是轻量手写 SVG，不引图可视化框架；不做"同时打开多个声优合并
  成更大图"（会滚雪球，违背本设计）。
