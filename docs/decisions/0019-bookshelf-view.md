# 0019 · 书架视图（第二种展示模式）

日期：2026-08-06
状态：已接受

## 背景

在现有网格海报卡之外，为图书馆区提供第二种展示模式——"书架/书脊"视觉
（窄条 + 竖排标题，贴近真实书架）。用户可自由切换，并接入现有主题体系与
筛选/排序逻辑。

## 一、书脊配色方案（关键决策）

### 需求
书脊主体颜色需要有差异（否则一排单色太单调），且要接主题色系、不引入
取色库/Canvas 分析。

### 备选方案
- **A. 封面主色提取**：用 Canvas 统计封面主色 → 书脊同色系。效果最好，但
  需要取色逻辑 + 封面必须可加载（跨域/无封面时退化），且对本地无封面的
  笔记类条目无解。
- **B. 规则分配（采用）**：由主题 `--accent` 做**色相旋转**，按条目的
  **主分类标签哈希**决定偏移量，饱和度/明度向"书脊质感的低饱和中明度"
  收敛。

### 为什么选 B
- **不脱离主题色系**：以当前主题 accent 为基准色相（`bookshelf.hexToHsl` +
  `spineColor`，accent 是 hex，如 spring `#ec4899`），色相旋转 +47°×seed
  得到一组同调性颜色，与任何主题都协调；不引入新的独立配色体系。
- **不引依赖**：纯数学（hex→HSL、hash），约 30 行；方案 A 需要取色库或
  Canvas 复杂度，且对无封面条目无效（任务明确"不要为了更精致引入新依赖"）。
- **有语义的"按分类归架"**：seed = 主标签（`primaryTag`，取第一个 tag）哈希，
  **同标签作品 → 相同色相**（实测：两个"恋爱"标签作品同为 `hsl(188,…)`、
  两个"RAG"作品同为 `hsl(106,…)`），观感像真实书架按分类码放；无标签用 id
  兜底（稳定）。
- 主题切换时 accent 变化 → 整架色调随主题一致变化（运行时读 CSS 变量）。

## 二、书脊卡片

- 窄条 36×236px（书脊宽高比 ≈1:6.5，参考真实书籍），圆角 + 左侧高光条 +
  底部装帧色带。
- 标题**竖排**：CSS `writing-mode: vertical-rl` + `text-orientation: mixed`
  （等效方案，无字体/Canvas 依赖）；过长裁剪（真实书脊也会裁标题）。
- **hover 抽书预览**：fixed 定位小卡片（`getBoundingClientRect` 计算位置，
  脱离横向滚动），显示封面缩略图 + 标题 + **我的评分**（hover 时才懒拉
  `fetchItemDetail` 取 `my_rating`，带缓存；null 不显示评分）。
- **点击书脊 → 打开详情**（复用现有 `openItemDetail`）。

## 三、视图切换

- 图书馆头部新增分段切换（▦ 网格 / ▤ 书架）。
- 选择持久化到 `localStorage["tsumugi-lib-view"]`（复用主题/导航顺序的
  localStorage 模式）；重挂载自动恢复。

## 四、排列逻辑

书架直接渲染现有 `libFiltered`（后端标签/分组筛选 → `gridItems` → 前端
`libQuery` 本地过滤），**不单独做一套筛选**。标签筛选、分组、本地查找在
书架视图下天然生效。

## 五、测试与实测

- **Vitest +14**（bookshelf.test.jsx）：
  - 纯函数：stringHash/spineSeed/primaryTag/hexToHsl/spineColor（同 seed 同色、
    不同 seed 异色、非法色回退）；
  - Bookshelf：渲染书脊 + 竖排标题、点击进详情、空书架、只渲染传入子集
    （筛选生效）、hover 拉评分显示/评分 null 不显示；
  - DesktopView 集成：默认网格 → 切书架写 localStorage → 重挂载恢复 →
    书架视图下本地查找筛选仍生效。
  - 全量 vitest **48 passed**；pytest **266 passed**（无后端改动）；build 通过。
- **实测（真实数据 + headless Edge）**：向真实后端写入 5 个带标签条目
  （恋爱×2、RAG×2、动漫/科幻×1），用真实 `bookshelf.spineColor` 计算配色并
  生成书架 HTML → headless Edge 渲染出 **800×380 PNG**（书脊签名合法）：
  - 5 根窄条书脊竖排标题，配色按主标签聚类（恋爱 `hsl(188)`、RAG `hsl(106)`、
    动漫 `hsl(223)`）；
  - 视图切换/持久化/筛选联动由 DesktopView 集成测试验证。
  - 测试数据已清理。
