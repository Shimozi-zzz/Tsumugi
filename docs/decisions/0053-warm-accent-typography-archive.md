# 0053 · 默认主题暖橙化 + 排版自信升级 + 档案编号系统

日期：2026-08-10
状态：已接受
基准：ADR 0020（token 体系，不新增第五套主题）+ AGENT_UI.md（排版自信/档案感，方向
借鉴 Hermes 的"排版自信、编号档案感"两点，不照搬其黑白工程语言）

## 一、默认主题（经典白）强调色暖橙化

- **新强调色**：`--accent: #b25b36`（暖棕橙 / 赤陶土调，略带灰调、不鲜艳），
  `--accent-hover: #9c4c2c`、`--accent-soft: #f9ede5`。
- **选择理由**：
  1. **色相**：hsl(18°) 落在"暖棕橙"带，参考 Claude 品牌赤陶土调性（不刺眼的暖色）；
  2. **略带灰调**：饱和度 0.45（非鲜艳橙），明度 0.45，让"确定感"与"温暖感"共存，
     契合 AGENT_UI"温暖记忆图书馆"定位；
  3. **对比度**：`#b25b36` 在浅底（#fff）对比 ≈4.7:1，达 WCAG AA——白字按钮、正文
     强调、小标签均可读；
  4. **与既有功能协调**：只改 `--accent` 系颜色变量，间距/圆角/阴影/密度结构 token
     不动；`--ambient-alpha`（氛围光强度）与封面取色（CoverAmbient/详情光晕/首页环境光）
     不依赖 accent，自动适配；依赖 accent 的进度条渐变、书脊色相旋转基准（原蓝 221°→
     暖橙 18°）随之成为暖色系，视觉统一。
- **其余三套主题**（薄荷/樱花/深色）**不动**（themes.js ACCENTS 与 index.css 各主题块
  未改；有测试锁定其色相）。
- 实现：`themes.js ACCENTS.default` + `index.css :root` 默认值（无 JS 兜底）。

## 二、排版自信升级（跨四套主题）

- 新增字体 token（对齐 AGENT_UI v2.2 ⑥）：`--font-heading`（Georgia/Songti/Noto Serif SC
  衬线栈）+ `--font-body`；关键标题用 `.tsm-heading`（衬线）。
- **只提升"应有强存在感的少数关键标题"**，正文/小字层级不动：
  - **详情页标题**：16px 无衬线 → **22px 衬线 semibold**（"打开这本书"的档案感）；
  - **记忆回廊页标题**：15px → 20px 衬线 semibold；
  - **记忆回廊年份标题**：11px 小字 → **ArchiveNo lg 大号衬线数字（30px）**；
  - **首页猫娘问候**：12px → 13px 衬线 weight500（轻声问候但有笔触）。
- 不做：全局放大字号、新字体下载。

## 三、档案编号系统（跨四套主题通用组件）

- **组件**：`ui.jsx` 新增 `ArchiveNo`（`§` 标记 + 等宽数字，`size="sm"` 条目级 /
  `size="lg"` 年份大标题；`color` 可 muted）；样式走 token（`--accent`/`--text-secondary`），
  CSS 在 `.archive-no`。
- **设计说明**：`§`（节号）做档案/引用气质的前缀标记（比 NO./# 更编辑、不代码味），
  数字用 tabular-nums 等宽、加字距，`lg` 用衬线大号——"被认真编目的私人档案"感；
  不照搬 Hermes 截图的字体/排布。
- **应用位置**（本质是被编目的档案）：
  - 记忆回廊**年份分组**：`§ 2026`（lg）；
  - Memory **时间轴条目**：`§01 §02…`（正序序号，muted）；
  - Review Studio **Records 书评列表**：`§01 §02…`（muted）。
