# 0035 · 声优图谱默认视图可读性修复（阈值 + 标签分级 + 碰撞避让 + 布局增强）

日期：2026-08-08
状态：已接受

## 一、问题（用户截图确认）

默认阈值 2 时，357 声优 + 56 作品 + ~1160 角色挤压成"实心圆饼"：中心节点间距趋近
0、所有节点文字标签无差别渲染导致大面积互相压盖、完全不可读。

## 二、修复方案

### 1. 默认阈值 2 → 3
实测各档规模：≥2 → 357 声优 / 56 作品；≥3 → **159 声优 / 56 作品**；≥5 → 41 声优。
默认取 **3**：仍保留较完整的跨作品网络（比 5 的 41 个更全），配合标签分级后节点量
（159 声优 + ~710 角色 ≈ 927 圆）虽多但以圆点为主、可读。阈值 2/3/5/8 四档切换保留，
用户可自行调疏。

### 2. 标签分级 + 碰撞避让（根治"标签糊在一起"）
- **分级**：只有"配音作品数 ≥ `LABEL_ACTOR_MIN`(=4)"的声优与全部作品才进入**标签
  候选**；其余声优/角色只显示圆点，**hover（`<title>`）显示名称**——不无差别渲染
  所有节点文字；
- **碰撞避让**（`pickLabels`）：候选按优先级（声优=配音作品数、作品=连接声优数）
  降序，贪心放置，与已放置标签的估算包围盒重叠则隐藏（低优先级让位）；选中的声优
  标签强制显示（`forcedKeys`）；
- **包围盒估算**：宽度系数 0.9×fontSize（中文全角 ≈1em，保守估宽），避免估算过窄
  导致实际仍重叠——实测 0 重叠。

### 3. 布局增强（根治"中心挤压成实心"）
- 迭代 70 → **160 轮**、最小间距 55 → **74**、排斥力增强、步长上限放宽；
- **确定性抖动初始化**：多个声优落到同一质心时，斥力向量会互相抵消而原地不动
  （对称坍缩）——加随索引变化的初始偏移打破对称，让斥力把节点散开；
- 节点坐标钳制在画布内（留边距给文字标签）；角色小圆点改小（r=2.6、低透明度）。

## 三、明确保留
- 交互不变：点声优 → 完整配音列表 + 子图高亮；点作品/角色 → 主从视图跳详情；
- 视觉仍走 token，不引入独立配色；布局仍是"确定性一次算完"的轻量 SVG（无实时
  O(n²) 帧循环），不引入图可视化框架。
