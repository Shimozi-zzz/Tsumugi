# 0034 · 封面动态取色氛围（Ambient Color from Cover Art）

日期：2026-08-08
状态：已接受

## 一、取色算法选型与计算位置

**计算位置：前端 Canvas 实时提取 + 缓存（不是后端预计算）。** 理由：
- 主从视图详情面板的封面**已被后端在收藏时缓存到本地**（`/static/thumbnails`，
  同源），浏览器可直接读像素；无需为取色结果加后端字段/迁移；
- 取色只在查看详情时发生，频率低；同一封面结果按 URL 缓存于模块级 Map（上限 200），
  切换条目不重算，满足性能要求；
- 与安利卡同款处理链（见下），复用已验证的防 taint 方案。

**算法：轻量直方图主导色**（`frontend/src/ambient.js`，不引图像库）：
- 图像缩小到 32×32 → 像素 RGB 粗量化（高 4 位 → 4096 桶）→ 按出现次数排序；
- 取**主导色** + **第二主色**（第二色需与主色 hue 差 >30° 或明度差 >0.2 才保留，
  避免相近色凑数）；
- **可读性优先降级**：主色饱和度过低（<0.10）/过黑（l<0.12）/过白（l>0.90）视为
  "不鲜明" → 返回 null → 前端回退主题表面色（不强行渲染看不清的效果）。

**防 taint / 加载策略**（复用安利卡"转 data URL 内联"经验并改进）：
1. 优先**直接加载原 URL 绘制**——同源 `/static` 缓存封面（含扩展名被猜成 `.img`、
   Content-Type 为 octet-stream 的）浏览器 `<img>` 会按内容嗅探解码，且同源不污染
   canvas，直接可读；
2. 跨域封面污染 canvas（`getImageData` 抛 SecurityError）→ 回退 `imageUrlToDataUrl`
   （CORS fetch → data URL，即安利卡方案）；非 CORS 远程返回 null 降级。
- 加载失败 / 环境不支持 Canvas → null（不阻塞详情渲染）。

## 二、克制程度参数（不可妥协的"可读性优先"）

氛围色是**表面色层级之上的一层背景光晕**，功能性元素（文字/按钮/边框）继续用主题
token 色：

- 渲染方式：详情面板一角（右上）的**柔和圆形光晕**，用 `box-shadow`（双层：120px
  大晕 + 52px 内晕）实现——box-shadow 可被 CSS transition 平滑动画，**切换条目时
  新封面取色就绪后颜色平滑过渡（0.5s）而非硬切**；
- **透明度（`--ambient-alpha` token，按主题定义）**：浅色主题 **0.16-0.18**（克制，
  避免刺眼），深色主题 **0.30**（深底上稍明显但仍有节制）；
- 光晕 `pointer-events: none`、z-index 在内容之下，不拦截任何交互；
- 无主色（降级）时 box-shadow 为透明 → 视觉回到纯表面色，无异常观感。

## 三、应用位置与范围

- **主从视图详情面板**（ADR 0029 的 ItemDetailPanel）：封面动态取色作为其背景氛围；
- 只对外部收藏（有封面）生效；本地笔记无封面 → 不触发取色、无氛围层；
- 四套主题（default/mint/sakura/dark）统一走 `--ambient-alpha` 与 accent 无关的
  取色色（氛围色取自封面本身，与主题 accent 无关，仅透明度随主题调整）。

## 四、测试与实测

- **vitest 137 passed**（+9 `ambient.test.jsx`）：`dominantColors` 纯红/纯蓝主色
  （色调差异）、纯白/纯黑/中灰 → null（边界降级）、透明像素跳过、红+绿 → 主色红
  次色绿（第二主色条件）、`isVivid`/`rgbToHsl` 边界；ItemDetailPanel 氛围光晕使用
  取色主色（boxShadow 含 rgb + 标题仍 var(--text)）、切换条目氛围色更新 + 有 0.5s
  transition、无封面本地笔记 → 透明且不触发取色）；build 通过。pytest 369（无后端
  改动）。
- **实测（真实 App + headless Chrome CDP，逐条目读光晕取色结果）**：
  - 纯色演示封面端到端：红 → `rgb(210,40,40)`、蓝 → `rgb(40,90,210)`、
    绿 → `rgb(40,170,80)`，**不同条目氛围色真实反映各自封面主色**；
  - **真实收藏条目**（本地缓存封面）：《命运石之门系列》→ `rgb(53,54,9)`（深橄榄
    调）、《魔法少女小圆》→ `rgb(183,197,188)`（浅灰绿调）——来自真实封面主色调，
    非预设；
  - **深浅主题克制对比**：浅色主题光晕 alpha=0.16（红封面），深色主题 alpha=0.30
    ——深色更明显但仍克制，文字/按钮保持 token 色不受影响；
  - 截图 `ambient_dark_red.png`。
  - 说明：批量导入的条目封面因当时网络波动未缓存本地（仅 2/61 有本地封面），远程
    lain.bgm.tv 本机当前不可达，故真实条目演示用了 2 个有本地封面的 + 3 个纯色
    演示封面（端到端验证，已清理）。
