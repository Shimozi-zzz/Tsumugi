# 0054 · 图书馆网格视图结构性重设计（Archive Grid 范本）

日期：2026-08-10
状态：已接受
基准：AGENT_UI.md（档案馆/编目感）+ ADR 0020（token 体系）+ 上一轮 ADR 0053（暖橙，已在）

## 〇、上一轮偏差的核实与说明

本轮任务前提是"上一轮做成了新增第四套主题"。经核实 `frontend/src/themes.js`：
`THEMES` 仍为 4 套（default/mint/sakura/dark），`ACCENTS.default` 已是暖橙
`#b25b36`——即上一轮（0053）**就是替换默认主题强调色，并未新增第五套**（有 themes
测试锁定色相为证）。故"第一步纠正偏差"无额外代码动作；但本轮核心的**网格结构性重构**
（独立于配色）按任务执行。

## 一、来源徽标重新设计（对应截图：封面左上角 accent 色块胶囊）

- **旧形态**：`<span class="…rounded-full" style="backgroundColor: var(--accent)">bangumi</span>`
  贴在封面图片左上角——"资源网站/模板"式"图片上盖章"语言。
- **新形态**：来源从封面移除，改为信息区**编目行里的文字标注**：
  `NO. 0003   BANGUMI`（来源用大写字距、text-secondary），与编目号同行、细分隔线。
- **为什么更符合档案馆**：实体档案馆/博物馆给馆藏贴标签是**文字标注/角落索引**，不覆盖
  藏品本身；图片是"藏品"，色块徽章是"第三方标签"。移出后封面完整干净，来源信息仍在
  编目行内可读——直接解决截图里"徽章压在封面上"的问题。

## 二、档案编号（藏品编目号，对应截图：卡片无任何编号）

- 每个卡片信息区顶部**编目行**：`NO. {id补零4位}`（如 `NO. 0003`），等宽数字
  （tabular-nums）、accent 色、加字距——"入库序号即藏品号"，呼应实体图书馆编目。
- 与标题（衬线）形成"编号=机器可读 vs 标题=人文"的对比；这是"被认真编目的私人收藏"
  的直接视觉证据（截图里旧卡片标题上方空无一物，无档案语境）。

## 三、卡片比例与排布（对应截图：统一大圆角容器、标题 13px 无衬线）

- **容器近直角**：`.archive-card` 圆角 6px（`--radius-lg` 16px → 近直角）；封面作为
  "馆藏实物"在内部保留 `--radius-sm` 中等圆角——遵循 ADR 0020"正文/面板近直角，
  封面可圆"原则，截图里旧卡片整体大圆角是模板观感。
- **内部排布节奏**（"不是机械均匀"的落点）：封面 → 细编目分隔线 → 编目行 → 留白 →
  衬线标题。网格仍对齐（档案馆的秩序感）；节奏差异来自**卡片内部层级**而非打乱网格
  （打乱网格会显得破损，不符合"秩序井然"的档案气质）。
- **标题**：13px 无衬线 → **15px 衬线（tsm-heading）semibold + line-clamp 2 + 上留白**，
  排版自信升级延续（0053）。

## 四、空态占位图（对应截图：无本地封面条目 = 大片灰块）

- **旧形态**：`--card-thumb` 灰渐变 + 一个首字/来源缩写（视觉上读作"灰色方块"）。
- **新形态**：`.archive-ph` 档案占位卡——居中**书脊轮廓线**（细描边 + 中脊线）+
  内细虚线边框 + `藏 · 0003` 编目号填充。
- **为什么**：灰块是"未完工技术产物"感；占位给出"待上架的档案卡"语义（书脊空位 +
  编目号），视觉上有内容、有档案语境——直接解决截图里"纯灰方块"问题。

## 五、实现与测试

- 新增 `ArchiveCard.jsx`（可复用组件 + `catalogNo` 纯函数 + `ArchivePlaceholder`）：
  grid 换用它；`.archive-card*`/`.archive-ph*` CSS 走 ADR 0020 token；颜色仍在暖橙体系。
- 不改书架/分组列表视图、不引入新配色、不转向黑白工程风（温暖档案馆方向）。
- vitest **225 passed**（+9 `archive-card.test.jsx`：catalogNo 补零、编目行/来源文字标注
  且封面内无徽章、标题衬线、占位非灰块、有封面正常、点击/右键/书评/删除/选择模式、
  本地不显来源）；build 通过。

## 六、实测（改动前后对比）

- 用 `git stash` 暂存本轮改动 → 旧网格（`.desk-card`）截图 **BEFORE**；恢复 → 新网格
  （`.archive-card` × 63 + 档案占位）截图 **AFTER**（同机同 app，非合成）。
- 对比可见结构性差异：① 来源徽章从封面移入信息区编目行；② 每个卡片出现 `NO. xxxx`
  编目号 + 编目分隔线；③ 容器圆角由大变小（近直角）、封面独立中等圆角；④ 标题变大
  变衬线；⑤ 无封面条目由灰块变为书脊轮廓+编号的档案占位。
