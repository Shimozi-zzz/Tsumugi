# 0078 · Phase 7-2：书架视觉结构重做（文献式真书架）

日期：2026-08-12
状态：已接受
基准：ADR 0049（真书架，层板线+分架+厚度+取书）、AGENT_UI.md【Book Shelf】、
ADR 0066（夜书房 token）、ADR 0072（圆角语义）

## 一、决策

对 `libView === "shelf"` 做视觉结构重做：每个分类 = 一个「书架单元」（分类索引 +
书架匣 + 层板），书 = 实体馆藏对象。**数据/交互/API 全冻结**：`spineColor` /
`spineSeed` / `spineThickness` / `groupBookshelf` / 点击进详情 / selectMode /
右键 / hover 数据请求 全保留。

## 二、为什么旧结构丑（审计结论）

1. **多本书排列（核心）**：书脊均值仅 11px（10–28px），63 本 = 一排彩色细柱；
   每分类一条可横滚细条 = 仍是"书脊贴成列表"（ADR 0019 的形态残留）。
2. **空间比例**：高 210 / 宽 11（≈19:1），读不出"书"的实体。
3. **层板**：7px 渐变条 + border-bottom = "画了一条线"，书没有站在上面的接触感。
4. **分类标题**：accent 左边条 + surface 底 + 边框的"目录卡标签"，比书更抢眼（badge）。
5. **构图**：页面 = 一叠横条，无"一格书架"的空间围合。
6. **hover**：`translateY(-6px)` + 远离书本的 fixed 大浮卡，非"抽书"。
7. **移动端**：390px 仍是 11px 细柱，不可用。

## 三、新视觉结构

- **书架单元**：`.shelf-unit`（分类）= `.shelf-index`（serif 分类名 + mono 册数 +
  hairline 延伸线）+ `.shelf-case`（hairline 围合 + 顶部微光的"一格书架"）+ 层板。
  索引比书安静（无 badge / 无彩色块）。
- **书（实体对象）**：`bookWidth()` 把数据厚度 9..28 映射到 **22..46px**（保留
  spineThickness 相对关系）；圆柱明暗（`::before` 90° 渐变）+ 顶部头带（`::after`）
  + 底脚 + 底部接触影；书名 vertical-rl，窄书（<20px）隐藏书名（当前映射下不触发）。
- **层板**：上表面亮 / 前缘暗 / 下垂影（13px 实体板，非 border 线），书"站"在上面。
- **色彩**：保留 spineColor 低饱和粉彩 + 数据映射；圆柱明暗/头带让色块呈现为
  "书的布料"而非"彩色 UI 柱子"。
- **hover = 抽书**：`translateY(-5px)` + 阴影加深 + CoverAmbient 环境光（radius 3）；
  预览贴近书本、半径 radius-cover、弱阴影（保留 评分/书评摘录/编目号 数据）。
- **选中态**：微 accent 外框 + 13px 小圆选择标记（非 checkbox 卡）。
- **移动端**：书脊最小 24px（`max(var(--sw),24px)`），杜绝不可用细柱；单架横向可浏览。
