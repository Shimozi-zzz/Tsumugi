# 0056 · 编目抽屉正式落地为默认设计系统

日期：2026-08-10
状态：已接受
基准：ADR 0054/0055（方向 B"编目抽屉"探索）+ ADR 0020（token 框架）+ AGENT_UI.md
说明：探索版方向 B 经用户选定，转正为 Tsumugi 的默认设计系统，覆盖全站。

## 一、主题范围决策：版式与配色分离（默认主题换色板，四套共享版式）

**判断**：编目号、索书卡字段罗列、近直角、字体搭配属于**版式/信息呈现方式**，可与配色
独立存在——"深色主题"完全可以用同一套索书卡版式，只是换个色板。故采用投入产出比最高的
方案：

- **版式（结构 token）全站统一（四套主题共享）**：近直角圆角（--radius-lg 16→10、
  --radius-sm 8→4）、`--font-heading` 衬线 + `--font-mono` 等宽、`.archive-*`/
  `.archive-no`/`.catalog-no` 编目号规则、InfoTable 索书卡字段罗列——薄荷/樱花/深色主题
  自动继承（它们使用同一套结构 token + 各自色板）。
- **配色（色板）默认主题替换**：默认（原"经典白"）整体换为米黄纸感色板；薄荷浅蓝、
  樱花粉、深色三套**保留各自色板**（其 --bg/--surface/--card-bg 等维持自身），仅共享新版式。
- 理由：① 四套主题各自设计一套"编目抽屉配色"性价比低，版式统一即可获得一致语言；
  ② 深色主题用纸感色板会失去夜间可读性，保留深色色板 + 索书卡版式是正确组合。

## 三、全站推广

- **图书馆网格**：探索版 ArchiveCard 转正为正式实现（编目行 `NO.xxxx · 来源`、近直角
  容器、封面保留稍圆、书脊轮廓占位），颜色随新色板自动纸感。
- **书架**：层板/书脊配色随 token 纸感化；**抽书预览加编目号**（`NO.xxxx`）；书脊太窄
  （10-28px）不加编号（判断：放不下，放预览里更有用）。层板线/厚度/分架逻辑不变。
- **详情页**：标题下加 `NO.xxxx` 编目号；"外部世界"的 InfoTable 本身就是索书卡字段罗列
  （label/value + 行分隔），随新色板呈现；"我的记录"时间轴已有 § 编号。
- **记忆回廊 / 时间轴**：年份 `§` 大号 + 条目 `§01` 已就位，继承新 token（字体/纸感）。
- **首页神殿**：**不硬加编目号**——神殿是"入口仪式"空间隐喻，大量编号罗列会破坏参拜
  仪式感；仅继承纸感底色 + 暖橙 + 衬线猫娘问候 + 封面氛围光（判断：哪些该引入、哪些
  保持现状，不为统一而生硬到处加）。
- **命令面板 / Toast / 批量操作栏**：跟随新色板/字体（它们用 --panel/--input-bg/--text
  等 token），不引入内容型编号。

## 四、保留已验证机制

- 封面动态取色氛围（详情/卡片 hover/书脊 hover）：仍用封面主色 + --ambient-alpha，在
  纸感底上以暖橙强调协调（实测验证）；不因换底色失效。
- 猫娘台词：位置/形式不变，视觉跟随新主题。
- 真书架层板线/厚度数据驱动/按标签分架逻辑不变，仅视觉随 token。
