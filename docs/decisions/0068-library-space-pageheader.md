# 0068 · Phase 2-1：Library 空间与页面头（私人书架的第一层）

日期：2026-08-11
状态：已接受
基准：ADR 0066（夜书房 Shell）+ Phase 2 设计命题（"打开书库，就像走进自己的书架"）

## 一、范围

Phase 2-1 只解决 Library 的**空间**：页面头、内容列宽、留白、移动基础结构。
不进入 ArchiveCard / 工具栏 / 状态分组 / 圆角全面迁移。

## 二、变更

1. **书架空间列（`.lib-space`）**：书库内容约束到舒适宽度（`max-width: 1600px`，居中），
   超宽屏（4K/全宽）下书架不会拉成一片；1920 以下内容自然填满。只做空间，不改内部。
2. **移动端基础结构**：`≤768px` 隐藏左侧侧栏（`[data-testid="left-sidebar"]`
   `display:none`）——移动端书库获得全宽（实测 390 下库列 105px→329px），避免
   "桌面缩小"式挤压；配合既有底部房间导航 + 主内容 64px 下边距。
3. 页面头沿用 Phase 1 `PageHeader`（书库 · LIBRARY），未重设计。

## 三、明确不做（本步）

- 不改 ArchiveCard 内部、工具栏、状态分组、圆角系统；
- 不改后端/模型/数据；ShellC 书库房间空间留待后续统一。

## 四、验证

- vitest **247 passed**；build 通过。
- 真实浏览器（Electron 离屏）：
  - 1920 / 1440：书库列填满内容区、无横向溢出；
  - 390：rail 隐藏、底部导航显示、侧栏隐藏后库列 329px 全宽、`hOverflow=false`。
