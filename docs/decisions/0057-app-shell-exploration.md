## 三方向空间设计主张

- **A 卡片抽屉导航**：左侧导航 = 一排真实卡片目录柜抽屉——每个抽屉有顶部标签（编号
  tab）、拉出式选中态；旁边一个"抽屉内容索引卡"；导航即"拉开哪一格目录柜"。
- **B 书脊索引栏**：左导航 = 一排立着的书脊（竖排衬线文字 + 编号），整条是"馆藏索引
  书脊"，站在一起、选中立起；宽度/比例不同于窄图标条。
- **C 非对称档案室**：打破"侧栏宽度全站统一"——不同页面进入不同"房间"：书库宽偏移、
  记忆回廊居中窄廊、人物馆右留白、关系厅左偏移、设置居中窄卡，房间格局各不相同。

## 访问方式（临时，非正式外壳）

- 任一页面右下角浮动开关：经典三栏 / A 卡片抽屉 / B 书脊索引 / C 非对称档案室；
- URL 直达：`/library?shell=a|b|c|classic`；
- localStorage 记忆选择；本轮只做默认主题下的探索。
