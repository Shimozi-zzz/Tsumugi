# 0071 · Phase 2-4：状态分组 → 书架分区

日期：2026-08-11
状态：已接受
基准：ADR 0066/0068/0069/0070 + Phase 2 命题（"我的书架分区"，不是"作品状态统计"）

## 一、书架章节标题

StatusGroupedList 的分组标题从"状态名 + 数量 pill"改为**书架章节标题**：
`▾ [状态名 serif 14px] ──(hairline)── [N 册 mono]`。
- serif 状态名（--font-heading）、hairline 细线（--panel-border → transparent）、
  mono 册数（--font-mono，--ink-2，**数量降权，非视觉焦点**）；
- 保留折叠/展开；状态值不变（想看/在看/看完/搁置/弃坑/未收藏）；行点击→右侧详情不变。
- 分区之间 `gap-5` 书架层节奏；**不套 Card**（无 Section 套 Card / Card 套 Card）。

## 二、侧栏分组 / 标签区（一并审视）

分组（全部/笔记/图片/外部收藏）与标签的数量从 `text-[11px]` 次级色改为
**mono 微字 `--ink-2`**——数量降权，当前选择仍用 accent 表达；标签/标签编辑/筛选逻辑不变。

## 三、空状态 / 颜色 / Motion

- 空分组不渲染（无"0 items"类数据库语言）；列表整体空时沿用既有"暂无资料。";
- 无状态专属颜色（收藏/在看/看完…不各一色），状态之间靠标题/空间/细线区分，
  仅折叠箭头用极少量 accent；实测列表视图实心 accent 元素 0；
- 无新动画（motion 仅折叠箭头已存在于 token 体系）。
