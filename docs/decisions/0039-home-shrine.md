# 0039 · 图书馆首页：神殿空间氛围（Layer 1，不含角色台词系统）

日期：2026-08-09
状态：已接受

## 一、范围与红线

首页/应用入口（默认的 ask 空态）重新设计为"神殿空间氛围"——**不含角色台词系统
（Layer 2 未来单独讨论）**、不含任何角色插画/视觉形象、不引入新图片资源。神殿感
通过**空间隐喻 + 留白 + 仪式节奏**传达，严格遵循 ADR 0020 收敛的主题 token（间距/
圆角/表面色层级/`--ambient-alpha`），配色走当前主题 accent/氛围色，不引入独立风格。

## 二、空间隐喻的具体设计手法

- **纵轴构图 + 大留白**：首页为全高（h-full）居中构图，纵向依次为
  鸟居轮廓线 → 搜索栏（焦点"祭坛"）→ 最近供奉，四周大幅留白，形成明确的视觉焦点，
  而不是平铺的功能入口列表；
- **极简几何符号（点到为止）**：SVG 勾勒的**鸟居轮廓线**（笠木微翘 + 贯 + 双柱 +
  中央加固，4 条 path，accent 色 40% 透明度）——是符号不是场景插画，暗示"入口/参拜"；
- **供奉式排布**：最近收藏的封面以**纵深/退级**方式排布——中心位最低最实、两侧随
  距离逐级升高变淡（translateY 每级 +12px、scale 降、opacity 降），配合"最近供奉"
  标签，形成"陈列供奉"而非网格；
- **氛围色驱动的环境光**：复用 ADR 0034 取色逻辑，以"最近活跃/最近收藏的代表封面
  （当前 = 最新外部收藏的封面）"主色生成顶部 radial 环境光（`--ambient-alpha × 0.7`
  更收敛）；首页随"最近在关注什么"变化色调；无数据/取色失败回退主题表面色（不发错）。

## 三、仪式过渡的触发频率设计（理由）

- **触发规则**：每天仅在**首次打开应用**时播放完整"揭幕"（暗幕 0.55 → 渐亮 + 内容
  渐次呈现，纯 CSS transition，总时长约 1.2s）；**同一天内**后续进入首页为简化版/
  无过渡。判定用 localStorage `tsumugi-home-ritual`（记录日期）。
  **理由**：完整过渡每次打开都播会从"仪式感"退化为"烦人的加载动画"；按"天"而非
  "会话"切分符合日常使用节奏（一天参拜一次），且实现成本低、可预测。
- **可跳过**：点击任意处 / 按任意键直接完成揭幕（`.shrine-skip` 关闭 transition，
  瞬时呈现），用户不想看随时可跳过。
- **坑位**：React StrictMode 会**双调 useState 初始器**——若在初始器里写
  localStorage 会提前消耗"当天已播放"标记导致仪式从不播放。因此 `shouldPlayRitual()`
  保持**纯查询**，在仪式 effect 真正播放时才 `markRitualShown()`（StrictMode 下
  双跑 effect 也无害）。
