# 0024 · Review Studio 视觉重做：排版驱动的沉浸感（回归主题收敛）

日期：2026-08-07
状态：已接受

## 为什么上一轮"Violet Obsidian 玻璃拟态"有问题（如实说明）

上一轮 Review Studio 做成了独立的"第四套视觉风格"：深紫透玻璃（`.rs-*`
作用域变量）＋ 1px 发光紫边框 ＋ 模糊封面背景。这**直接违反了 ADR 0020 的
主题收敛方向**——该 ADR 明确反对"各主题各自为政 / 独立视觉风格"，而工作室
却脱离三套收敛主题（经典白/薄荷/樱花）自成体系：切换全局主题时工作室观感
不变，像"贴上去的另一个 App"。用户已指出，本轮是修正而非延续。

## 本轮方案：排版驱动的沉浸感（保留结构，只换视觉语言）

**信息架构不变**：左参考区四标签（Overview/Records/Archive/Memories）＋
右编辑器，原样保留。

### 1. 移除玻璃拟态，接入全局主题 token
- 删除 `.rs-*` 硬编码紫色变量、发光边框、`backdrop-filter` 模糊、独立 `--rs-*`
  作用域；
- 面板/标签/输入/引用卡改用 `--panel / --panel-border / --shadow-sm|md /
  --radius-lg|md / --accent / --accent-soft / --input-bg / --text / --text-secondary`
  （与全 App 一致）；切换全局主题，工作室自然跟随。

### 2. 排版驱动的沉浸感（核心）
- **阅读宽度**：编辑区正文限定 `max-width: 720px` 居中，不撑满容器；
- **行高**：正文 `line-height: 1.78`；
- **衬线字体**：正文用 `Georgia, "Songti SC", "Noto Serif SC", "STSong", serif`
  ——与界面其余部分（无衬线）形成对比，制造"专门写作空间"的质感（参考
  iA Writer / Bear 的排版逻辑，不是视觉特效）；
- **进入书写模式时应用 chrome 淡出**：工作室以**主题底色不透明覆盖** + 淡入，
  不再用模糊盖住——背后的顶部导航等自然被隐藏。
- **打字机聚焦效果**：跳过（需按段落跟踪光标计算透明度，复杂度与收益不成
  比例），记入未来可选项。

### 3. 一个克制的点缀（只做一个）
- 实现**字数进度条**：编辑区上方一条 2px 纤细的**强调色渐变进度条**
  （`linear-gradient(90deg, accent, accent 55% 透明)`），以 500 字为软目标；
  用现有 accent，不引入新配色。
- 未做"光标处强调色呼吸"，避免堆砌。

### 4. 进出过渡（纯 CSS）
- 进入：`.review-studio` 挂 `rs-enter`（opacity 0→1 + translateY(10px)
  scale(0.985) 展开，0.28s cubic-bezier）；
- 退出：组件先加 `.closing` 走 `rs-leave`（0.18s 淡出），`setTimeout(180ms)`
  后再真正卸载——关闭也平滑。

## 明确不做
- 不改变左右对照信息架构；不做纸质纹理（未来可选项：可在正文加极淡的
  米白纸感，本轮先做主干）；不做打字机聚焦以外的复杂动效。

## 测试与实测

- **vitest 81 passed**（+3：三套主题下渲染且 token 接入——断言无 `--rs-*`/
  紫罗兰硬编码、含 `var(--text)/var(--accent)/var(--panel-border)`；进入/退出
  过渡——点返回先加 `.closing` 再 180ms 后调 onClose；字数进度条 250 字→50%）。
  既有工具栏/字号/Records/预览/引用卡/Archive 用例保持通过。
- pytest **309 passed**（无后端改动）；build 通过。
- **实测（headless Edge，真实 CSS + 真实条目数据）**：三套主题（default/mint/
  sakura）下工作室各渲染一张 1280×760 有效 PNG——主题底色/面板/强调色随主题
  变化，正文为衬线 + 720px 阅读宽度 + 1.78 行高，与全局视觉语言**真正统一**，
  不再是独立风格。
